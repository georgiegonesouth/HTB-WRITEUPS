# HTB-WRITEUPS

## A collection of writeups about HackTheBox Vulnerable Machines.

### This is meant to be educational and fun, not to promote illegal activities

#### Each box folder is set up this way:
|file|purpose|
|----|-------|
|writeup.md|An explanatory narrative of the hacking process|
|target.md|Info about the machine|
|lessons.md|Key takeaways|
|flags.md|Retrieved flags|
|credentials.md|Passwords/Hashes/Keys|
